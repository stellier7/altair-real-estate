# Real Estate Web Design

Act as the visual design director for a premium real-estate website.

The website should feel like:

* a high-end architectural publication
* a luxury property portfolio
* a sophisticated modern real-estate/investment firm

It must NOT look like:

* a generic realtor template
* a SaaS dashboard
* an AI-generated website template
* a marketplace listing site

## Design philosophy

Prioritize:

* exceptional property photography
* strong typography
* editorial composition
* generous whitespace
* architectural inspiration
* sophisticated hierarchy
* restrained UI
* subtle premium motion
* excellent responsive design

Prefer:

* cinematic hero sections
* large editorial imagery
* asymmetric layouts
* full-bleed photography where appropriate
* intentional whitespace
* sophisticated hover states
* immersive property galleries
* strong typography
* carefully composed sections

Avoid:

* excessive cards
* excessive rounded corners
* excessive shadows
* generic gradients
* glassmorphism
* generic corporate blue
* repetitive three-column layouts
* excessive badges and pills
* unnecessary UI
* cheesy real-estate aesthetics
* excessive animation

## Photography

Treat photography as one of the primary design elements.

Property imagery should be large, carefully cropped, and visually dominant.

Do not reduce important property imagery to small thumbnails unnecessarily.

## Typography

Create a clear typographic hierarchy:

* display typography
* section headings
* body copy
* metadata
* labels

Use typography confidently but avoid excessive font sizes or weights.

## Layout

Favor editorial and architectural compositions over repetitive card grids.

Use:

* asymmetric compositions
* large margins
* intentional whitespace
* varied section heights
* strong alignment
* occasional overlapping elements
* full-width visual sections

Not every section should be a collection of cards.

## Property pages

Property pages are the centerpiece of the website.

They should feel immersive and editorial rather than like database records.

The visual hierarchy should communicate:

1. property identity
2. location
3. atmosphere
4. key specifications
5. property story
6. features
7. location/context
8. supporting materials
9. contact/action

## Property cards

Property cards should prioritize:

1. photography
2. property name
3. location
4. relevant status/type
5. price or CTA when appropriate

Do not display every property attribute inside a card.

## Motion

Use subtle, sophisticated motion:

* image reveals
* smooth hover states
* restrained page transitions
* gallery transitions
* subtle scroll reveals

Never use animation simply for decoration.

Respect `prefers-reduced-motion`.

## Responsive design

Design intentionally for:

* large desktop
* laptop
* tablet
* mobile

Do not simply shrink desktop layouts.

Mobile layouts should preserve the visual hierarchy while simplifying compositions where necessary.

## Accessibility

Maintain:

* semantic HTML
* sufficient contrast
* keyboard navigation
* visible focus states
* meaningful alt text
* accessible controls
* reduced-motion support

## Quality test

Before accepting a design, ask:

* Does this look like a generic real-estate template?
* Are there too many cards?
* Are there unnecessary rounded containers?
* Are there too many shadows?
* Is the typography generic?
* Is the layout repetitive?
* Is the photography receiving enough visual importance?
* Is there too much UI competing with the property?
* Does the mobile layout feel intentionally designed?

If yes, refine it.

The final visual language should feel:

CONFIDENT.
ARCHITECTURAL.
EDITORIAL.
PREMIUM.
RESTRAINED.
INTENTIONAL.
